# Nagpur Pulse — Unified Frontend Integration Documentation

## Architecture & Overview
The **Nagpur Pulse** frontend platform integrates all three specialized traffic & emergency applications into one unified production-ready web application:
1. **Nagpur Police Unit Command & Dispatch**
2. **Nagpur Traffic Monitor**
3. **Nagpur Traffic Incidents & Accident Monitor**

## Authentication & Authorization (RBAC)

The application supports persistent session management and role-based access control (RBAC):
- **Roles**: `ADMIN`, `POLICE_COMMANDER`, `DISPATCHER`, `TRAFFIC_OPERATOR`, `ANALYST`, `VIEWER`.
- **Permissions**:
  - `POLICE_COMMANDER` / `DISPATCHER` / `ADMIN`: Full unit dispatching, 112 triage, status modification, and simulation reset.
  - `TRAFFIC_OPERATOR`: Traffic inspection, corridor search, signal flow analysis.
  - `ANALYST`: ML risk predictions & coverage gap analysis.
  - `VIEWER`: Read-only public traffic & incident stream.

## Unified Map System (`UnifiedMap.tsx`)

The shared Leaflet map engine supports multi-layer toggle:
- `Traffic Layer`: Congestion color circles & live speed badges.
- `Incident Layer`: Accident & hazard pins with detailed popup windows.
- `Police Unit Layer`: Patrol vehicle markers, siren strobe indicators, and unit status.
- `Route Layer`: GeoJSON polyline generated by backend `RoutingService`.
- `Risk Layer`: Heatmap rings for high & critical risk predicted junctions.
- `Coverage Layer`: 1.2km police station coverage circles.
